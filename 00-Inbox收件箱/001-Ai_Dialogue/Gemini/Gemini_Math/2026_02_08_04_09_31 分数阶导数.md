# 从拉普拉斯变换视角定义分数阶导数：理论全集

## 1. 数学背景与预备知识

在探讨分数阶导数之前，必须明确两个核心数学工具：**伽马函数 (Gamma Function)** 和 **卷积定理 (Convolution Theorem)**。

### 1.1 伽马函数

作为阶乘在实数/复数域的推广，它是分数阶微积分的阶数因子：

$$\Gamma(z) = \int_0^\infty e^{-t} t^{z-1} dt, \quad \text{Re}(z) > 0$$

性质：$\Gamma(n+1) = n!$。

### 1.2 拉普拉斯变换的卷积性质

若 $F(s) = \mathcal{L}\{f(t)\}$ 且 $G(s) = \mathcal{L}\{g(t)\}$，则：

$$\mathcal{L}\{f(t) * g(t)\} = \mathcal{L}\left\{ \int_0^t f(t-\tau)g(\tau) d\tau \right\} = F(s)G(s)$$

## 2. 整数阶导数的启发

对于 $n$ 阶导数 $f^{(n)}(t)$，其拉氏变换为：

$$\mathcal{L}\{f^{(n)}(t)\} = s^n F(s) - \sum_{k=0}^{n-1} s^{n-1-k} f^{(k)}(0)$$

当所有初值 $f^{(k)}(0) = 0$ 时，变换简化为：

$$\mathcal{L}\{f^{(n)}(t)\} = s^n F(s)$$

**逻辑延伸：** 若要定义 $\alpha$ 阶导数（$\alpha \in \mathbb{R}^+$），我们寻找一个算子 $D^\alpha$，使其在零初值条件下满足：

$$\mathcal{L}\{D^\alpha f(t)\} = s^\alpha F(s)$$

## 3. 分数阶积分：一切的起点

定义 $\alpha$ 阶积分（Riemann-Liouville积分）是通向分数阶导数的必经之路。 考虑到 $n$ 阶重复积分公式：

$$J^n f(t) = \int_0^t \frac{(t-\tau)^{n-1}}{(n-1)!} f(\tau) d\tau$$

将 $(n-1)!$ 替换为 $\Gamma(\alpha)$，得到 $\alpha$ **阶积分算子**：

$$J^\alpha f(t) = \frac{1}{\Gamma(\alpha)} \int_0^t (t-\tau)^{\alpha-1} f(\tau) d\tau = f(t) * \frac{t^{\alpha-1}}{\Gamma(\alpha)}$$

### 拉氏变换推导：

由于 $\mathcal{L}\left\{\frac{t^{\alpha-1}}{\Gamma(\alpha)}\right\} = \frac{1}{s^\alpha}$，根据卷积定理：

$$\mathcal{L}\{J^\alpha f(t)\} = \frac{1}{s^\alpha} F(s) = s^{-\alpha} F(s)$$

## 4. 主流分数阶导数的拉氏变换定义

设 $n-1 < \alpha \le n$（$n$ 为向上取整后的整数）。

### 4.1 Riemann-Liouville (R-L) 分数阶导数

**定义：** 先进行 $n-\alpha$ 阶积分，再进行 $n$ 阶微分。

$$_0D_t^\alpha f(t) = \frac{d^n}{dt^n} \left[ J^{n-\alpha} f(t) \right] = \frac{1}{\Gamma(n-\alpha)} \frac{d^n}{dt^n} \int_0^t (t-\tau)^{n-\alpha-1} f(\tau) d\tau$$

**拉氏变换过程：**

$$\mathcal{L}\{D_{RL}^\alpha f(t)\} = s^n \mathcal{L}\{J^{n-\alpha} f(t)\} - \sum_{k=0}^{n-1} s^{n-1-k} [J^{n-\alpha} f(t)]^{(k)} \Big|_{t=0}$$

代入积分变换公式：

$$\mathcal{L}\{D_{RL}^\alpha f(t)\} = s^\alpha F(s) - \sum_{k=0}^{n-1} s^k [D^{\alpha-k-1} f(t)]_{t=0}$$

### 4.2 Caputo 分数阶导数

**定义：** 先进行 $n$ 阶微分，再进行 $n-\alpha$ 阶积分。

$${}_0^C D_t^\alpha f(t) = J^{n-\alpha} \left[ \frac{d^n}{dt^n} f(t) \right] = \frac{1}{\Gamma(n-\alpha)} \int_0^t (t-\tau)^{n-\alpha-1} f^{(n)}(\tau) d\tau$$

**拉氏变换过程：**

$$\mathcal{L}\{D_{C}^\alpha f(t)\} = s^{-(n-\alpha)} \mathcal{L}\{f^{(n)}(t)\}$$$$\mathcal{L}\{D_{C}^\alpha f(t)\} = s^{-(n-\alpha)} \left[ s^n F(s) - \sum_{k=0}^{n-1} s^{n-1-k} f^{(k)}(0) \right]$$

**整理得到：**

$$\mathcal{L}\{D_{C}^\alpha f(t)\} = s^\alpha F(s) - \sum_{k=0}^{n-1} s^{\alpha-k-1} f^{(k)}(0)$$

## 5. R-L 与 Caputo 的深度对比

|特性|Riemann-Liouville (R-L)|Caputo|
|---|---|---|
|**定义顺序**|先积分后微分|先微分后积分|
|**拉氏变换初值项**|分数阶导数的初值（物理意义不明确）|整数阶导数的初值（物理意义明确）|
|**常数的导数**|不为 0（而是 $t^{-\alpha}/\Gamma(1-\alpha)$）|等于 0|
|**工程应用**|较少，主要用于理论数学|广泛应用于力学、控制、工程建模|

## 6. 线性变换性质的严谨证明

分数阶导数算子 $D^\alpha$ 是一个线性算子。

### 6.1 证明过程

设 $h(t) = a f(t) + b g(t)$，其中 $a, b$ 为常数。 以 Caputo 定义为例：

$${}^C D^\alpha (af(t) + bg(t)) = \frac{1}{\Gamma(n-\alpha)} \int_0^t (t-\tau)^{n-\alpha-1} \frac{d^n}{d\tau^n} [af(\tau) + bg(\tau)] d\tau$$

由于整数阶导数是线性的：

$$\frac{d^n}{d\tau^n} [af(\tau) + bg(\tau)] = a f^{(n)}(\tau) + b g^{(n)}(\tau)$$

由于积分运算是线性的：

$${}^C D^\alpha h(t) = a \left( \frac{1}{\Gamma(n-\alpha)} \int_0^t (t-\tau)^{n-\alpha-1} f^{(n)}(\tau) d\tau \right) + b \left( \frac{1}{\Gamma(n-\alpha)} \int_0^t (t-\tau)^{n-\alpha-1} g^{(n)}(\tau) d\tau \right)$$

故得出：

$$D^\alpha (a f + b g) = a D^\alpha f + b D^\alpha g$$

### 6.2 频域视角证明

通过拉氏变换观察：

$$\mathcal{L}\{D^\alpha (af + bg)\} = s^\alpha (a F(s) + b G(s)) - \text{初值项}$$

在零初值条件下：

$$\mathcal{L}\{D^\alpha (af + bg)\} = a (s^\alpha F(s)) + b (s^\alpha G(s)) = a \mathcal{L}\{D^\alpha f\} + b \mathcal{L}\{D^\alpha g\}$$

这从频域角度验证了其线性叠加性。

## 7. 结论

通过拉普拉斯变换，我们将复杂的时域卷积积分（分数阶导数）转化为了简单的频域代数乘法（乘以 $s^\alpha$）。

- **R-L 定义** 在数学上更具一般性，但在处理初值时存在困难。
    
- **Caputo 定义** 成功将分数阶系统的初值问题与物理可测的整数阶初值挂钩，是分析线性分数阶系统（Fractional Linear Systems）最有效的工具。
