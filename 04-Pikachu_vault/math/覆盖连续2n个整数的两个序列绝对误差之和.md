> [!question] 问题0
> $n$为任意正整数，令$a_1<\cdots<a_n,b_1>\cdots>b_n$并且$$\{a_1,...,a_n,b_1,...,b_n\}=\{1,\cdots,2n\}$$证明$$\sum_{i=1}^n|a_i-b_i|=n^2$$

### 1. 做法1：考虑对$\min\{a_i,b_i\}$求和
#### 1.1 简化问题

首先我们可以尝试使用$$|x-y|=x+y-2\min\{x,y\}$$来把绝对值拆开，一般在一个涉及到处理和的问题当中对被求和对象如此操作，我们往往可以去除问题中不重要的部分，集中精力对付整个问题中关键的部分。

在这个问题当中，因为$\sum_{i=1}^{n}(a_i+b_i)$是不重要的，因为两个序列组成的集合的并是1到2n当中全部的整数，因此$$\sum_{i=1}^{n}(a_i+b_i)=n(2n+1)$$于是我们真正要证明的是:

> [!question] 问题1.1.1
> $n$为任意正整数，令$a_1<\cdots<a_n,b_1>\cdots>b_n$并且$$\{a_1,...,a_n,b_1,...,b_n\}=\{1,\cdots,2n\}$$证明$$\sum_{i=1}^{n}\min\{a_i,b_i\}=\frac{n(n+1)}{2}$$

#### 1.2 通过计算机提出猜想

接下来我们可以借助计算机的算力来帮助我们得到一些随机的例子，以辅助我们完成"先猜再证"。

```mathematica
GenerateLists[n_] := 
 Module[{nums, firstList, secondList},
 (*Step 1: 生成从1到2n的整数的一个列表*)
 nums = Range[1, 2 n];
  (*Step 2:从列表当中随便选取n个数，并排序*)
  firstList = Sort[RandomSample[nums, n]];
  (*Step 3:给剩下的n个数做相反的排序得到另一个序列*)
  secondList = Sort[Complement[nums, firstList], Greater];
  (*Step 4:最后输出两个列表*)
  {firstList, secondList}]
```

首先我们可以替换n，多次重复下面的代码:
```mathematica
n = 18;
{a, b} = GenerateLists[n];
Table[Min[{a[[i]], b[[i]]}], {i, 1, n}] // Sort
```
我们发现$\min\{a_i,b_i\}$这个序列能取遍从$\{1,...,n\}$当中的每个数。借助下面的代码
```mathematica
n = 18;
{a, b} = GenerateLists[n];
Table[{a[[i]], b[[i]]}, {i, 1, n}]
```
我们提出一个猜想:

> [!note] 猜想1.2.1
> $n$为任意正整数，令$a_1<\cdots<a_n,b_1>\cdots>b_n$并且$$\{a_1,...,a_n,b_1,...,b_n\}=\{1,\cdots,2n\}$$令$c_i:=\min\{a_i,b_i\}$那么$c_i$彼此不同并且取遍$\{1,\cdots,n\}$当中的每个数。

* 首先因为$a_i,b_j$彼此之间互不相同，因此$c_i$是$n$个不同的正整数。
* 把$\{1,\cdots,2n\}$分为两集合$A:=\{1,2,\cdots,n\}$以及$B:=\{n+1,\cdots,2n\}$，那么每一对$(a_i,b_i)$必然一个落在$A$另一个落在$B$否则会导致矛盾。因为假设存在某个$i$使得$a_i\leq n,b_i \leq n$那么由于$a$递增，$b$递减，于是$$a_1,\cdots,a_i\leq n,\quad b_i,\cdots,b_n\leq n$$这两个序列互不相交，于是至少有$i+(n-i+1)=n+1$个元素落在$A$这个集合当中。但这是不可能的。
* 既然任意的$(a_i,b_i)$都有一个元素落在$A$这个集合中，那么自然$c_i$取遍全体$A$当中元素，因此猜想得证。


因此猜想1成立，原来的问题得证。


### 2. 做法2：交换求和次序

对于被求和对象$|a_i-b_i|$我们可以把它也展开为一个和的形式$$|a_i-b_i|=\sum_{k=1}^{2n-1}1\{\min\{a_i,b_i\}\le k<\max\{a_i,b_i\}\}$$然后我们可以把目标和写成一个双重求和，并交换次序$$\begin{aligned}S&:=\sum_{i=1}^{n}|a_i-b_i|\\&=\sum_{i=1}^{n} \sum_{k=1}^{2n-1}1\{\min\{a_i,b_i\}\le k<\max\{a_i,b_i\}\}\\&=\sum_{k=1}^{2n-1}\sum_{i=1}^{n}1\{\min\{a_i,b_i\}\le k<\max\{a_i,b_i\}\}\\&=\sum_{k=1}^{2n-1}T_n(k)\end{aligned}$$其中$$T_n(k):=\sum_{i=1}^{n}1\{\min\{a_i,b_i\}\le k<\max\{a_i,b_i\}\}$$

所谓交换求和次序无非就是从另一个角度来完成目标求和。那么为什么新的求和方式究竟具有什么优势，值得我们去交换呢？

> [!tip] 关键的观察
> 我们发现，$T_n(k)$是一个与序列$a_i,b_i$当中元素具体的值无关的不变量！
> 
> 我们不妨用mathematica代码试验一下：
> 
> ```mathematica
> TForK[k_Integer, a_List, b_List] := 
>   Count[MapThread[(Min[#1, #2] <= k && k < Max[#1, #2]) &, {a, b}], 
>    True];
> ```
> 
> 配合上前文第一节当中随机生成序列$\{a_i\}_{i=1}^n,\{b_i\}_{i=1}^n$的代码，我们可以反复实验
> 
> ```mathematica
> n = 12;
> k = 17;
> (*生成10组随机的序列*)
> Table[{a, b} = GenerateLists[n]; TForK[k, a, b], {i, 1, 10}]
> (*最后会发现在不改变n,k的情况下，结果都一致*)
> ```
> 
> 最后发现，无论随机生成的两个序列是怎样的，最后的结果只与$k$以及$n$有关，与序列的具体值的分布无关。

接下来我们用数学来论证一下这种不变关系：

$T_n(k)$本质上是对$i$的计数，由于$a_i\neq b_i$，那么具体来说
$$\begin{aligned}T_n(k)&=\sum_{a_i<b_i} 1\{a_i\leq k<b_i\}+\sum_{b_i<a_i} 1\{b_i\leq k<a_i\}\\&=\#\{i:a_i\leq k<b_i\}+\#\{i:b_i\leq k<a_i\}\end{aligned}$$结合$\{a_i\}\cup\{b_i\}=\{1,2,\cdots,2n\}$以及两个序列的单调性，假设一共有$x$个下标满足$a_i\leq k$然后$y$个下标满足$b_i\leq k$，那么一定有$$x+y=k$$因为小于等于$k$小的值一共就是$k$。然后:
1. 因为$a_i\leq k<b_i$等价于$a_i\leq k$并且去掉$b_i>k$的部分,所以$$\#\{i:a_i\leq k<b_i\}=\#\{i:i\leq x \text{ and } i\leq n-y\}=\min\{x,n-y\}$$
2. 同样的道理可以得到$$\#\{i:b_i\leq k<a_i\}=\#\{i:i\geq x+1 \text{ and } i\geq n-y+1\}=n-\max\{x,n-y\}$$
于是综上所述$$\begin{aligned}T_n(k)&=\min\{x,n-y\}+n-\max\{x,n-y\}\\&=n-(\max - \min)\\&= n-|n-y-x|\\&=n-|n-k|\end{aligned}$$
于是$$S=\sum_{k=1}^{2n-1}(n-|n-k|)=n^2$$于是问题就被解决了。
