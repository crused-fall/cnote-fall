#### 1.2 递归定义的序列

> [!tip] 想法1.2.1  
> 利用[RecurrenceTable](https://reference.wolfram.com/legacy/language/v14/ref/RecurrenceTable.html?v=14.0)函数。这个函数被用来专门定义没有具体表达形式，符合某个递归定义的序列。
> 
> 此外当我们要计算的序列的项很大时，如果直接使用符号表达进行递归，函数运行效率会很低。这个时候把递归表达当中某个值写成浮点数的形式，可以让递归过程中得到的值全变成浮点数，从而大幅度提高效率。

一些典型的例子：
* [[Re0微积分1：用牛顿迭代法求算术平方根#^1cb6da]]:此处我们要做的数学实验是模拟序列$x_k$，其初值$x_1:=100$，满足的递归表达来自于牛顿法计算算术平方根$$x_{k+1}=\frac{1}{2}\left(x_k+\frac{2}{x_k}\right)$$不过为了计算效率着想，我们把前面的系数$\frac{1}{2}$从符号变成了数值$0.5$这样就能提高效率。其实如果我们把初值$x_1:=100$变成$x_1:=100.0$也可以让整个迭代当中产生的每一个$x_k$的值都是浮点数。不过代价就是精度会下降。
* [[关于序列极限的公开问题#^34f56a]]:在这个问题当中我们进行的数学实验模拟的对象是，初值为随机正实数$a_1:=b$，满足递归表达$$a_{n+1}=a_n+\frac{n}{S_n}$$的序列。其中因为涉及$a_k$的前$n$项和$S_n$，因此此处涉及两组递归。额外的一组为$$S_{n+1}=S_n +a_{n+1}$$以及第二组初值$S_1:=a_1$。
* [[利用Stolz定理确定递归序列的渐近系数#^2c6e36]]:这里我们模拟的对象是初值为$x_1:=1$并且满足递归表达$$x_{n+1}=x_n+3\sqrt{x_n}+\frac{n}{\sqrt{x_n}}$$的序列。由于要计算$n\leq 5,000,000$的所有值，因此在写代码的时候把其中递归定义式当中的系数$3$换成了$3.0$以提升速度。此外由于这个数学实验的最终目的是猜出猜出$x_n$在$n^2$这一项的渐近系数，于是最后把计算出来的数据配合[ListPlot](https://reference.wolfram.com/language/ref/ListPlot.html)函数绘制出了对应图像。
* [[利用Stolz定理确定递归序列的渐近系数2#^7229be]]:和上面例子目的几乎一致的一个实验，只不过这一次的对象为，初值$y_1:=1$迭代式子为$$y_{n+1}=\frac{2y_n}{2+y_n}$$的递归表达。此外RecurrenceTable这个函数对递归表达并没有严格要求方程左边一定是$y_{n+1}$右边只含有$y_{n}$的形式。即便我们不按照原文的方式定义该序列而是改为：

```mathematica
data = RecurrenceTable[{y[n + 1] == y[n] - y[n]*y[n + 1]/2, y[1] == 1.0}, y, {n, 1, 200}];
```
   
   也并不会有什么特别的影响。

* [[关于黄金比例数的迭代序列#^c4b26f]]:同样是以猜渐近行为目的的一次实验。实验对象初值为$x_1:=0.5$满足的递归表达为$$x_{n+1}^2=x_n+1$$最后用的是[ListPlot](https://reference.wolfram.com/language/ref/ListPlot.html)函数绘制出图像。
