当我们初学一个数学命题/结果/定理的时候，我们要如何增加自己对它的理解，并把这种理解遵照[[数学笔记写不出来自己的东西怎么办#^1ca7d5]]的原则把我们的理解写一写？

我们大致有下面五种策略：
1. 验证某个条件的必要性（给出缺失条件情况下的反例）
2. 给出自己的正面的符合这个命题的具体案例
3. 找到它与我们已知的结果的关系，并阐述这个关系
4. 吸收命题证明中的idea
5. 找到命题的用法

当然我们并不是每遇到一个结果就要把这些策略都用上一遍，而是把这些策略当作一种打开局面，增加对新认识的结果理解的一种手段。

### 1. 案例1

> [!note] 定理1.1:Bolzano - Weierstrass定理
> $\mathbb{R}^n$当中的有界序列都存在一个收敛的子列。

假设我们要对这个结果使用策略1,那么我们需要看看，是否能找到一个一定不存在收敛子列的无界序列。

我们想到下面这样的例子：

> [!例子1.2]
> 考虑序列$x_n=n$然后我们想到用利用[[柯西收敛判别#^e811c6]]来断定该序列不存在任何收敛的子列。
> 
> 由于对任意的$n_k>n_l$而言$|x_{n_k}-x_{n_l}|=|n_k-n_l|\geq 1$因此不符合柯西收敛判别，因此该序列的任意子列都不可能是柯西列。

> [!tip] 技巧1.3
> 事实上“定理1.1"的结果来自于Amann的分析学第一卷，像这种在看书过程中遇到的命题，要找它的应用最好就是直接用关键词检索，找到这个结果在这本书后面的应用。

比如通过检索我们可以找到在Amann的书关于Bolzano-Weierstrass定理的后面章节中的一个应用:

> [!note] 定理1.4
> $\mathbb{R}^n$是一个Banach空间。

* 我们要证明任意柯西列$\mathbb{R}^n$当中的柯西列$x_n$都收敛。由于$x_n$是柯西列，那么其必然有界，而有界序列由Bolzano - Weierstrass定理可知存在一个收敛的子列。而柯西列的性质告诉我们，子列收敛那么序列本身也收敛到同一个值。

### 2. 案例2 

下面这个案例来自于Edmund Hlawka的《Geometric and Aanlytic Number Theory》

> [!note] 命题2.1 
> 令$\alpha$是任意无理数，那么存在无限多个既约的有理数$\frac{p}{q}$满足不等式$$\left|\alpha-\frac{p}{q}\right|<\frac{1}{q^2}$$

稍微读了一下证明以后我们就发现这样一个事实，其实要找这种有理逼近不需要对于每个无理数都想不同的构造，只要找到一个无理数的连分数逼近就可以了。

所以要我们“看见”这个命题的结果也非常简单，我们只要做两个数学小实验就可以了。

我们需要分别找出无理数$\alpha=\pi,e$的连分数的展开，然后提取其中部分分数$\frac{p_k}{q_k}$然后计算$E_k:=q_k^2|\alpha - \frac{p_k}{q_k}|$最后判断是否每一个$E_k$都是小于1的即可。

结果如下：

![[pi的连分数逼近.png]]
![[e的连分数逼近.png]]

代码：

```mathematica

(* 主函数：给定 alpha 与 n *)
ConvergentCheck[alpha_, n_Integer?Positive] := Module[
  {a, cf, convs, p, q, vals, tbl},
  a     = N[alpha, 80];                 (* 数值化，给足精度 *)
  cf    = ContinuedFraction[a, n];
  convs = Convergents[cf];
  p     = Numerator   /@ convs;
  q     = Denominator /@ convs;
  vals  = N[q^2*Abs[a - p/q], 60];      (* 误差乘 q^2 *)

  (* 表格输出 *)
  tbl = Prepend[
    Transpose[{Range[Length[convs]], p, q, vals}],
    {"k", "p_k", "q_k", "q_k^2 |α - p_k/q_k|"}
  ];
  Print[Grid[tbl, Frame -> All]];

  (* 是否全都 < 1 *)
  Print["All Ek < 1 ?  ", AllTrue[vals, NumericQ[#] && # < 1 &]];

  (* 作图 *)
  ListLinePlot[
    vals,
    AxesLabel -> {"k", "q_k^2 |α - p_k/q_k|"},
    PlotRange -> {All, {0, 1.05}},
    GridLines -> {None, {1}},
    GridLinesStyle -> Directive[Red, Dashed],
    PlotMarkers -> Automatic,
    PlotTheme -> "Scientific",
    ImageSize -> Large
  ]
]

(* 用法示例 *)
ConvergentCheck[Pi, 20];
ConvergentCheck[E, 20];        (* 注意：自然常数用大写 E *)
ConvergentCheck[Sqrt[2], 20];
ConvergentCheck[Log[2], 20];


```
